# Café Isla Verde — Sitio Web (React + Vite + Tailwind)

SPA con secciones: **Inicio**, **Quiénes somos**, **Carta**, **Contacto**.

## Requisitos
- Node 18+
- npm

## Instalación
```bash
npm install
npm run dev
```
Abrir: http://localhost:5173

## Producción
```bash
npm run build
npm run preview
```

## Personalización
- Reemplaza imágenes en `src/pages/CafeIslaVerdeSite.jsx` → objeto `ASSETS`.
- Edita menú en `MENU` (categorías e items).
- Cambia dirección, teléfono y mapa en la sección **Contacto**.
